# 日程管理

一个清晰、轻量的个人日程管理网页，适用于比赛、运动、工作、学习和生活安排。

## 使用方式

直接使用浏览器打开 `index.html`，无需安装任何依赖或启动服务。

## 功能

- 按周查看日程，并快速切换上一周、下一周或回到今天
- 分类管理比赛赛事、运动训练、工作、学习和生活日程
- 新增、编辑和删除日程，记录时间、地点与备注
- 按类型筛选，并自动统计本周事项和运动时长
- 使用浏览器本地存储自动保存数据
- 支持邮箱账号登录，在手机和电脑之间同步日程
- 适配桌面端、平板和手机

## 开启云端同步

1. 打开 Supabase 项目的 **SQL Editor**
2. 复制并执行 [`supabase-setup.sql`](supabase-setup.sql) 中的全部 SQL
3. 在网页中点击“登录同步”，使用邮箱注册或登录
4. 在手机和电脑上登录同一账号

日程表已启用行级安全策略，每个账号只能访问自己的数据。本地日程会在第一次登录时自动上传到云端。
