# 人生管理系统

一个纯静态、零依赖的个人人生管理网页：观测并经营自己的日程、目标、训练、习惯、阅读、旅行，以及塔罗 / 八字 / 紫微的玄学空间。

## 使用方式

直接用浏览器打开 `index.html`，无需安装任何依赖或启动服务。数据默认保存在浏览器本地（localStorage），可随时通过侧边栏「导出数据 / 导入数据」进行 JSON 备份与迁移。

点击侧边栏「登录同步」可通过邮箱注册/登录。同一账号在手机和电脑登录后，日程、目标、训练、习惯、书单、旅行及玄学记录会自动同步。

## 功能模块

- **人生总览**：年度活跃热力图（训练 / 打卡 / 完成日程）、目标进度、未来日程、今日塔罗与生活切片
- **目标管理**：按人生领域（健康、事业、成长、体验、财务、关系）管理年度目标，关键结果（KR）勾选自动计算进度
- **我的日程**：周视图日程（沿用原有数据），比赛 / 运动 / 工作 / 学习 / 生活分类，支持完成标记
- **训练记录**：跑步、游泳、HYROX、潜水、力量训练日志，近 12 周时长图表，自动统计个人最佳（最长距离、最佳配速、最大潜深等）
- **习惯打卡**：最近 7 天快捷打卡、连续天数（streak）、本月热度月历
- **阅读书单**：想读 / 在读 / 读完，阅读进度、评分与摘录笔记
- **旅行足迹**：心愿清单与已完成旅程，记录日期、花费与游记
- **云端同步**：Supabase 邮箱认证，首次登录自动上传本机数据，之后修改自动同步；重新打开网页时读取最新云端数据
- **玄学空间**：
  - 塔罗：内置 78 张牌（含正逆位牌义），每日一牌与三牌阵，抽牌日志可写下自己的解读
  - 八字：输入公历生日排出四柱干支、藏干与五行分布（节气采用通式近似，±1 天误差）
  - 紫微：基础排盘，十二宫 + 十四主星、五行局、命宫身宫

玄学内容仅供自我觉察与娱乐参考。

## 技术说明

- 纯 HTML / CSS / JavaScript，无构建步骤，`file://` 直接打开即可运行
- `assets/common.js` 提供 hash 路由、存储、弹窗等应用壳能力，各模块独立成文件
- 农历转换使用经典 1900–2100 压缩表，日柱以 2000-01-01（戊午日）为锚点推算
- 响应式适配桌面端、平板和手机

## Supabase 初始化

项目已经配置公开的 Supabase Project URL 与 publishable key。首次使用云同步前：

1. 打开 Supabase Dashboard 的 **SQL Editor**
2. 新建查询，复制并执行 [`supabase/schema.sql`](supabase/schema.sql)
3. 在 **Authentication → URL Configuration** 中把网页地址加入 Redirect URLs（仅邮箱确认跳转需要）
4. 如希望注册后立即登录，可在 **Authentication → Providers → Email** 关闭 Confirm email；保留开启则需要先点击确认邮件

`schema.sql` 会创建 `life_data` 表并启用 Row Level Security。每个登录用户只能读写自己的数据。
