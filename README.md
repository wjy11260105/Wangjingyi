# 拾光学习库

一个类似在线文档的个人学习空间，用于整理学习笔记、课程、文章和视频链接。

## 使用方式

直接使用浏览器打开 `index.html`，无需安装任何依赖或启动服务。

## 愿望清单

仓库里还有一个独立页面 `wishlist.html`，是一个动态愿望清单：

- 在输入框写下愿望并许愿，气泡带入场动画
- 点击气泡即可在「已实现 / 未实现」之间切换，点亮时有庆祝彩带
- 已实现的愿望以实色胶囊 + 对勾 + 划线呈现，未实现的为虚线描边胶囊
- 支持编辑、删除，以及「全部 / 未实现 / 已实现」筛选
- 顶部实时统计已点亮数量与完成进度条
- 数据使用浏览器本地存储自动保存，直接打开 `wishlist.html` 即可使用

## 功能

- 使用富文本工具栏编辑学习笔记，支持标题、列表、引用和链接
- 新建、收藏和保存个人文档
- 集中整理文章、视频和课程，并按类型筛选
- 为学习材料添加摘要、标签和收藏状态
- 支持关键词搜索，以及 `⌘/Ctrl + K` 搜索和 `⌘/Ctrl + S` 保存快捷键
- 使用浏览器本地存储自动保存数据，无需登录或后端
- 适配桌面端、平板和手机
