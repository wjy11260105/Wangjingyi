# 人生观测站

这是在原日程管理网页旁独立开发的新版人生管理系统。当前版本不会覆盖根目录的 `index.html`。

## 功能结构

- 人生总览：目标、习惯、运动、阅读和人生领域状态
- 日程安排：周视图及目标、项目关联
- 目标与项目：将长期方向拆解为阶段成果
- 习惯追踪：每日打卡、周记录和连续天数
- 周期复盘：周、月、季度和年度结构化复盘
- 成长记录：跑步、游泳、HYROX、潜水、阅读和旅行
- 内在感悟：塔罗、紫微、八字及一般感悟的手动记录

## 本地预览

直接打开 `life-system/index.html`。首次进入会显示示例数据，并自动读取旧版浏览器中的日程数据。

## 启用云端同步

1. 在 Supabase Dashboard 打开 SQL Editor
2. 完整执行根目录的 `supabase-life-system.sql`
3. 打开新版网页，使用原有 Supabase 邮箱账号登录
4. 在手机与电脑登录同一账号

同步采用本地优先策略。每条记录包含 `updated_at`，手机和电脑会保留时间较新的版本；网络失败时，本地记录不会丢失。

## 数据隐私

所有业务表均开启 Row Level Security。云端查询、写入、更新和删除都要求 `auth.uid() = user_id`，每个账号只能访问自己的数据。玄学相关内容仅作为个人反思记录，不提供自动排盘或决策建议。
